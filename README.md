# Starfield Item IDs

A searchable list of the Form IDs of every item you can spawn with the Starfield console, read from the official game files (game version 1.16.244.0): the base game, Shattered Space, Terran Armada, Free Lanes, Trackers Alliance and Watchtower.

**View it here:** https://taosecurity.github.io/starfield-item-ids/

- 6,019 items in 14 groups: weapons, spacesuits, helmets, boost packs, apparel, ammo, aid, food and drink, resources, misc items and valuables, books and slates, keys, weapon mods and armor mods. Each group lists the main game first, then each add-on.
- Click an ID or a ready-made command (`player.additem <ID>`, or `amod <ID>` for mods) to copy it. A Count box adds a quantity to every command.
- Add-on IDs depend on load order. The page starts from the game's built-in order, and you can set each add-on's prefix to match your own game; the page explains how.
- Search by name, ID or editor ID, and filter by where an item comes from.

Made by Richard Bejtlich of [Richard Presents Starfield Essentials](https://www.youtube.com/@RichardBejtlich). Also see [Starfield Console Commands](https://taosecurity.github.io/starfield-console-commands/), [Starfield Record Types](https://taosecurity.github.io/starfield-record-types/) and [Tracking Starfield on Nexus Mods](https://taosecurity.github.io/NexusModsMetrics/).

## Notes

- This is an unofficial list, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media. Item names are the game's own.
- Left out: records the game marks as not playable, ship weapons and ammo, creature attacks and skins, test and cut records, and companion- or enemy-only weapon copies.
- The IDs were not tried in the game one by one. Base game and Shattered Space IDs were spot-checked against other published lists.
- The list is regenerated after game updates.

The page is a single self-contained `index.html` with no external dependencies. Its code (layout, search, copy and load-order features) is MIT licensed; see `LICENSE`.
