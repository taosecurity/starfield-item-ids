How to use

click to hide

Spawn an item

Open the console with the ~ key (PC only) and type player.additem <ID> <count>. For example player.additem 0000000F 1000 gives you 1,000 credits. Leave the count off for one. Set Count in the search bar and every command on the page uses it.

Using the console turns achievements off for that save.

Add a mod to a weapon or suit

Mods aren't inventory items. Drop the weapon or armor on the ground, open the console, click it to select it, then type amod <ID>. Pick it up again afterwards. A mod only fits the weapon or armor it was made for, and one mod per slot.

Add-on IDs depend on load order

Base game IDs start with 00 and are the same for everyone. Add-on IDs start with a prefix that depends on where the add-on loads: 01, 02… for full plugins, FD + 2 digits for medium ones (Trackers Alliance), FE + 3 digits for light ones. Items marked load order use the prefixes in Your load order; change them there if yours differ.

Check an ID in your own game

Type help "<name>" 4 in the console, for example help "Va'ruun Starstorm" 4. It lists matching records with the ID your game uses. If the first digits differ from this page, set that add-on's prefix under Your load order.

How load order prefixes work

Why add-on IDs differ between players

A Form ID has two parts: a prefix that says which file the item comes from, and the item's own number inside that file. Take Va'ruun Starstorm, 0100EEE4:

  • 01 is the prefix: "the second file loaded", which by default is Shattered Space.
  • 00EEE4 is the Starstorm's own number. It never changes.

The base game always loads first, so its prefix is always 00 and base game IDs are the same for everyone. Each add-on's prefix depends on where it sits in your load order. If something loads ahead of Shattered Space in your game, its prefix becomes 02, and the Starstorm is 0200EEE4 for you.

There are three kinds of prefix, depending on how the add-on file is built:

  • Full files (Shattered Space, Terran Armada, Free Lanes, Watchtower) get 2 digits: 01, 02, 03…
  • Medium files (Trackers Alliance) get FD plus 2 digits, such as FD05. The item number after it is 4 digits.
  • Light files get FE plus 3 digits. No light file currently adds spawnable items.

What the page assumes

The game has a built-in order for its official add-ons. The default prefixes follow it: Shattered Space 01, Terran Armada 02, Free Lanes 03, Watchtower 04, and Trackers Alliance FD00 and FD02 to FD07.

Shattered Space, Terran Armada and Free Lanes are built in, so their defaults should be right for most players. Watchtower and Trackers Alliance load from your plugin list, so any mod placed above them shifts their prefix. Those two are the ones most likely to differ.

How to set yours

  1. Find your real prefix. In the console, type help "Watchtower Equinox" 4. It shows the ID your game uses, for example 05077C43. The first two digits (05) are your Watchtower prefix.
  2. Enter it on the page. In Your load order, click Watchtower's prefix box, change 04 to 05 and press Enter.
  3. Every ID updates. All Watchtower items on the page, and their copy-ready commands, now start with 05.

Details

  • Items whose ID depends on load order have a load order label next to the ID. Base game items have no label and never change.
  • The page checks what you type. A prefix in the wrong shape (for example zz, or 05 for a Trackers Alliance file that needs FD plus 2 digits) gets a red outline and is ignored.
  • Your prefixes are saved in your browser, so they're still there next time you open the page. Reset to defaults clears them.
  • Each Trackers Alliance file (sfta01 to sfta06, plus SFBGS003) has its own prefix. If they're off, checking one item from each file tells you all of them.
  • Your load order changes when you add or remove mods. After a big change, a quick help check on one item from each add-on keeps the page in step with your game.

About this list

  • Read from the Steam copies of the official game files for Starfield 1.16.244.0: Starfield.esm, ShatteredSpace.esm, SFBGS050.esm (Terran Armada), SFBGS00D.esm (Free Lanes), SFBGS003.esm and sfta01-06.esm (Trackers Alliance), and kinggathcreations_spaceship.esm (Watchtower). Names are the game's English names.
  • Left out: records the game marks as not playable, ship weapons and ammo, creature attacks and skins, test and cut records, and companion- or enemy-only copies of weapons. A few odd entries may remain; the editor ID column helps you tell look-alikes apart.
  • Unique and legendary weapons (such as those from quests) are mostly built from a normal weapon plus mods, so they don't have their own entries here. Legendary effects are listed under the mod groups.
  • The IDs were not tried in the game one by one. They are the game's own records; base game IDs were spot-checked against other lists.
  • A game update can add items; the list is regenerated after updates.
